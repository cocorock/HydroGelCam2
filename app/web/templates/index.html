Preprocessing pipeline

Equations

{% if t == "uniformity" %}

Uniformity index

UI = 1 − CV = 1 − SDD̄
D̄ = 1N ∑Di,   SD = √ ∑(Di − D̄)²N − 1
Di
filament thickness at one sample point
N
measurements currently checked (filaments × positions)

UI = 1 is a perfectly uniform filament. UI → 0 means scatter approaching the mean — pulsating extrusion, entrapped air, a partial clog, or stick–slip flow. Valid only for CV < 1.

Spreading ratio

SR = D̄Dn
Dn
nozzle inner diameter (input above)

SR = 1 is dimensional fidelity. SR > 1 is spreading — die swell, gravitational flattening, or over-extrusion. SR < 1 is stretching, from nozzle speed outrunning volumetric flow or too great a print distance.

UI is precision, SR is accuracy. A filament can be perfectly uniform and uniformly too wide.

{% elif t == "fusion" %}

Diffusion rate

Dfr = At − AaAt × 100 %
At
theoretical pore area, below
Aa
measured pore area

0 % means no spreading (Aa = At); 100 % is a fully closed pore.

Theoretical pore area

At = (a − d)²
a
arista — design nozzle-path spacing for that size class
d
filament diameter, shared across classes

The open pore is what is left between two filaments laid a apart, so it is smaller than a by one filament width. With a = 1 mm and d = 0.41 mm the pore is 0.59 mm across and At = 0.348 mm² — the label “a = 1 mm” names the spacing, not the opening. Undefined when a ≤ d: the design leaves no pore at all.

Printability index

Pr = L²16 Aa
L
pore perimeter

Referenced to an ideal square. Rounded, under-gelated pores fall below 1; irregular, over-gelated pores rise above it. Acceptance window {{ defaults.pr_window[0] }}–{{ defaults.pr_window[1] }} (Ouyang et al.).

Circularity

C = 4πAaL²

C = 1 for a circle, π/4 ≈ 0.785 for a square. Cannot exceed 1 for any realisable shape.

Pr and C are the same measurement: C ≡ π/(4Pr) for any area and perimeter, so they can never disagree. Segmentation quality is judged instead by pass-1/pass-2 area agreement and pore solidity, shown as per-pore flags.

{% else %}

Collapse factor

Cf = AsagAmax × 100 %
Asag
area between the pillar-top line and the filament underside
Amax
nominal gap × pillar height (total collapse)

0 % is a flat bridge; 100 % is fully collapsed, or a filament that never bridged.

The source paper states both directions. §2.4.3 says 100 % for a filament that does not collapse; the Results and Fig. 3d say a lower factor means less deformation. They are exact complements, and the selector on the left switches between them — the stored geometry is the same either way.

Deflection angle

θ = arctan sag depthanchor distance

Between the pillar-top horizontal and the line from the anchor to the deepest point of the sag. Smaller θ is a more stable filament.

Auxiliary

Atstrip = gap × df
df
filament diameter, measured on the pillar tops where it is not deflecting
